# Employee Onboarding Assistant

## Overview
An AI-powered assistant designed to simplify employee onboarding.

## Objectives
- Answer common employee questions.
- Provide information about company policies.
- Reduce repetitive HR tasks.
- Escalate sensitive questions to HR.

## Technology Stack
- n8n
- OpenAI
- Google Sheets
- GitHub
- Claude Code

## Project Status
In Progress
## Key Features

- Employee onboarding support
- AI-powered question answering
- HR escalation for sensitive queries
- Company policy information

## Safety

The assistant does not replace HR.
Sensitive or unclear questions must be referred to HR.
