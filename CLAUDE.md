# Project Instructions

## Project Name
Employee Onboarding Assistant

## Project Purpose
Build an AI assistant that helps new employees understand company policies and onboarding procedures.

## Technology Stack
- n8n for automation
- OpenAI for AI-powered responses
- Google Sheets for data storage
- HTML, CSS and JavaScript for frontend

## Development Conventions
- Keep the code simple and readable.
- Explain changes before making them.
- Do not invent company policies.
- Use only verified documentation when answering employee questions.
- Escalate sensitive questions to HR.
- Never expose API keys or passwords.
- Ask before making major changes.
